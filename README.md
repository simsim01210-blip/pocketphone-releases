# Pocket Phone

Minecraft 1.20.1용 Fabric 클라이언트 모드입니다.

**[모드 다운로드](https://github.com/simsim01210-blip/pocketphone-releases/releases/latest)**

- Fabric Loader 0.16.14 이상과 Minecraft 1.20.1용 Fabric API가 필요합니다.
- 배포 페이지에서 `pocket-phone-1.20.1-1.0.0.jar`를 받아 `mods` 폴더에 넣으세요.
- 기존 파일을 교체할 때는 게임을 먼저 종료하고 이전 Pocket Phone JAR을 백업하세요.
- 기본 키: ↑ 휴대폰 열기 / M 설정

이 저장소는 완성된 모드 배포용입니다. 개발 소스코드는 공개하지 않습니다.
`latest.json`과 `SHA256SUMS.txt`는 자동 업데이트와 파일 검증용입니다.
GitHub가 자동 표시하는 Source code ZIP/TAR에는 이 저장소의 안내문만 들어 있습니다.
